# Проверка кода ученика

Короткий код ученика во всей трилогии — ровно **4 символа** (например, `K7M2`).
Старые коды игры 8 класса выглядели как `P` + 4 знака (`P7X4K`); при первом
запуске они приводятся к 4 символам (`7X4K`), а журнал учителя продолжает
считать их тем же учеником.

```bash
node tools/account-audit/check-codes.js
```

Скрипт не требует браузера и зависимостей: он загружает `shared/account.js`
в изолированный VM-контекст с заглушкой `localStorage` и проверяет:

- генератор всегда выдаёт 4 символа из разрешённого алфавита;
- `canonicalShortCode()`: `P7X4K → 7X4K`, `k7m2 → K7M2`, мусор и пробелы;
- миграцию старого кода из `physicsquest8_settings` и из аккаунта;
- что обычный 4-символьный код не меняется;
- что в `shared/storage.js` есть `canonicalStudentCode()` / `sameStudentCode()`
  и что журнал учителя сравнивает коды через них;
- что в подсказках кабинета учителя больше нет примеров `P1234` / `P5678`.

Ожидаемый вывод: `17/17 проверок пройдено`.
