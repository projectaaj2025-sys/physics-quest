# Проверка автономных однофайловых сборок

`physics-quest-8.html` и `physics-quest-9.html` в корне репозитория собираются скриптом
`tools/build-standalone.js` из `play.html` и проверяются этим аудитом.

```bash
node tools/build-standalone.js
node tools/standalone-audit/check-standalone.js
```

Требуется `jsdom` (он же нужен аудитам в `tools/account-audit`):

```bash
npm i jsdom
```

## Что проверяется

1. **Самодостаточность** — ни одного `<script src>`, внешнего `<link>`, `manifest.json`
   или `src="assets/…"`; при загрузке jsdom не делает ни одного внешнего запроса.
2. **Запуск** — игра грузится без ошибок консоли, уровни отрисованы, банк заданий в памяти,
   карточка уровня открывает брифинг, кнопка «Начать миссию» запускает уровень и HUD боя.
3. **Фиксированный класс** — файл открыт с `?grade=7&code=TEST`, но `CURRENT_GRADE`
   остаётся 8 / 9.
4. **Ссылки** — клик по странице полного сайта и по переключателю классов даёт подсказку,
   а не переход в пустоту.
5. **Открытие с диска** — тот же файл грузится как `file://`; если браузер запрещает
   `localStorage`, подставляется хранилище в памяти, ошибок нет.

Текущий результат: **50/50**. Подробности — `docs/playthrough/lesson42-standalone-games.md`.
