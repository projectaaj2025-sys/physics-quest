# Браузерный аудит и скриншоты

Скрипты работают с реальным DOM текущей версии игры. Они не заменяют официальные PhET-симуляторы: во время capture внешний iframe блокируется, а в `phet-tasks-g*.png` сохраняется только собственная панель практических заданий интеграции.

## Запуск

Из корня репозитория запустить сервер:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

В другом терминале:

```bash
cd tools/ui-audit
npm ci
export AWS_EXECUTION_ENV=AWS_Lambda_nodejs22.x
npm run audit
```

Можно запускать проверки отдельно: `audit:content`, `audit:lessons`, `audit:phet`, `audit:gallery`. Адрес сервера меняется через `PQ_BASE_URL`, каталог JSON-отчётов — через `PQ_AUDIT_DIR` (по умолчанию используется системный временный каталог).

## Что проверяется

- `audit-content.mjs` — все 3675 заданий: RU/KK/EN, текст правильного ответа, формулы, пустой и сохранённый правильный ответ, строгий разбор числовых значений.
- `audit-lessons.mjs` — 153 урока на desktop и 153 на mobile, вкладки теории, индексы/степени, переполнение, все семь типов на трёх языках, верный/неверный ответ и показ решения после пяти попыток, светлая и тёмная темы.
- `audit-phet-levels.mjs` — 17 тематических связей уровней на RU/KK/EN, отсутствие старого каталога и общих кнопок, мобильная ширина, 9 циклов «мини-игра → PhET → задание → возврат» с сохранением состояния и фокуса.
- `audit-gallery.mjs` — RU/KK/EN, фильтры классов, PhET-раздел, счётчики, доступность всех изображений, lightbox, тема и мобильная ширина.

Любой дефект или JS-ошибка даёт ненулевой код выхода.

## Обновление кадров

```bash
npm run capture
```

Команда перезаписывает 31 текущее изображение в `assets/screenshots/`: 15 собственных мини-игр, окна заданий 7–9, тёмный вариант для 8 класса, три конспекта, три тематические PhET-карточки, три панели заданий и три полные галереи классов. PhET открывается нажатием карточки внутри реальной мини-игры; перед записью проверяется принятие числового ответа и отметки 3/3 через кнопки самоконтроля.
