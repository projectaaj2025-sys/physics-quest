# Аудит «Битвы экипажей» с телефонами

`check-battle-room.js` поднимает доску (`play.html?grade=8`) и семь телефонов
(`battle.html?room=…`) в headless-DOM и проходит весь путь: комната → заявки →
лобби → старт → ответы → финал.

PeerJS в песочнице недоступен, поэтому используется локальная комната
`BroadcastChannel`; каналы в тесте общие для всех окон (как вкладки одного браузера).

```bash
npm i jsdom
node tools/battle-audit/check-battle-room.js
```

Проверяется: все подключившиеся видны доске, потерянная заявка повторяется сама,
переподключение не создаёт дубль, опоздавший получает предупреждение и не ломает игру,
ответы всех участников доходят, финал показывает всех по именам, в локальном режиме
видно предупреждение, ошибок консоли нет.

`docs/playthrough/lesson43-battle-roster.md`.
