# Урок 42. Отдельные HTML-файлы игры для 8 и 9 класса

**Запрос:** «скинь мне отдельными хтмл игры для 8 и 9 классов, прям сюда можно».

**Результат:** два самодостаточных файла в корне репозитория — `physics-quest-8.html`
(7,69 МБ) и `physics-quest-9.html` (7,46 МБ). Внутри каждого — вся игра своей параллели:
разметка, стили, 52–53 скрипта, банк заданий и картинки этого класса. Ссылок на сервер,
на соседние папки и на интернет нет: файл открывается двойным щелчком или отправляется
ученику в мессенджере.

---

## Что сделано

| Шаг | Файл | Что дает |
| --- | --- | --- |
| Сборщик | `tools/build-standalone.js` | Берёт `play.html`, список модулей нужной параллели и загрузочный блок; вшивает CSS, JS и картинки в один файл |
| Картинки | тот же | `assets/comics/g8-*`, `g9-*` и сертификаты этого класса ужимаются до 1000 px / q70 и переводятся в data-URI; комиксы других классов и печатные PDF заменяются заглушкой «есть в полной версии» |
| Класс | тот же | Класс зафиксирован: `window.CURRENT_GRADE`, `body[data-grade]`, заголовок вкладки. `?grade=7` в адресе ничего не меняет |
| Хранилище | тот же | Если браузер запрещает `localStorage` на `file://`, подставляется хранилище в памяти — игра работает, прогресс живёт до закрытия вкладки |
| Ссылки | тот же | Клик по ссылке на портал, методичку, экраны или другой класс перехватывается подсказкой вместо перехода в никуда |
| Офлайн-модуль | тот же | `shared/offline.js` и `shared/offline-manifest.js` в сборку не попадают (им нужны 275 файлов сайта) |

Пересборка:

```bash
node tools/build-standalone.js        # 8 и 9 классы → physics-quest-{8,9}.html
node tools/build-standalone.js 7      # при необходимости 7 класс
node tools/standalone-audit/check-standalone.js
```

Файлы лежат в корне рядом с `play.html` и попадают в репозиторий: их можно скачать
(`Code → Download file` или raw-ссылка) и открыть, а после публикации GitHub Pages —
просто дать ученикам ссылку `/physics-quest-8.html`.

## Что работает и чего нет

**Работает:** все уровни и задания своего класса, аркадный бой, лаборатории и симуляторы,
режим учителя, классы и коды учеников, назначения уроков, приём результатов по коду
`R2-…`, карточки с QR, сертификаты, три языка, тёмная тема, звук, сохранение прогресса
на устройстве.

**Не работает (и почему):**

- портал, методичка, экраны, страница «Битва экипажей» — это отдельные страницы сайта;
- вход ученика по ссылке и подключение телефонов к доске — нужен общий адрес в интернете
  (файл, отправленный в мессенджере, у каждого свой);
- печатные PDF и комиксы других классов — не вшиты, чтобы файл не вырос до 30+ МБ
  (вместо них аккуратная заглушка «есть в полной версии»).

Для класса, где нужны назначения и сбор результатов с разных устройств, используйте
полную версию сайта; автономный файл — это «личный тренажёр» ученика.
